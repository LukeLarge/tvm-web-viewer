# Security Policy

## Supported Versions

We provide security updates for the versions listed as "Supported" in the table below.
Older versions do not receive security updates.

| Version | Supported          |
| ------- | ------------------ |
| 5.1.x   | :white_check_mark: |
| 5.0.x   | :x:                |
| 4.0.x   | :white_check_mark: |
| < 4.0   | :x:                |
